# Plataforma Rita Lobato
Esse projeto é um guia gratuito de informações sobre as Universidades Públicas que contém o curso de **Medincina**.

O objetivo é centralizar conteúdos educacionais gratuitos, permitindo que estudantes possam obter informações da forma de ingresso das universidades, locais dos campus, classificações nos rankings e os auxílios que a faculdade oferece.
